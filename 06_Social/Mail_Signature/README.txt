Al Deafah International Group - email signature
Two versions: ADIG_Mail_Signature_White.html (light) and ADIG_Mail_Signature_Black.html (dark), each with PNG fallbacks (@1x, @2x).
1. Edit the fields in [brackets] in the HTML.
2. Upload the "images" folder to a web server (or the company site) and replace "images/..." in the src/srcset attributes with the public URL.
3. Outlook (Windows): Signature settings > New > paste the rendered HTML (open the file in a browser, select all, copy, paste). Gmail: Settings > Signature > paste the same way. Apple Mail: paste the rendered HTML into a new signature.
Fonts: Arial is the manual's fallback for email (Avenir Next and Almarai cannot be embedded in email). Logo: Left lockup, CMYK on white / NEG on Deafah Black, from the masters. Pattern strip: 13 whole tiles, no tile is cut.
